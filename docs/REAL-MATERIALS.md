## 先发现书籍，再整理发言

按用户2026-10-21的纠正，选材顺序改为：全群提取书名候选→去掉昵称/@引用、接龙、重复转发、小助手和可识别AI粘贴→复核泛概念/影视同名等歧义→看提及消息、不同导出署名和跨日期交流→按书分组整理原发言。现有游戏书架不作为候选词种子。

当前报告在`evidence/real-materials/20261021-qianyi/discussion-discovery/BOOK-DISCUSSION.md`；16个前列标题候选经过人工复核，五组19条原发言已按书归档。消息提及数不是完整对话数或读后感数；同一显示名也不代表经核验的真实身份。

`analyze-weflow-books.py`从源数据里的书名号构造词表，再搜索不带书名号的提及；语义复核文件记录电影、泛概念、同名版本和原著引文等取舍。图片、语音与不带书名的连续交流没有自动计数，报告是保守检索结果。

## 编辑与来源规则

- 保留具体生活、口语、未读完和不同意见；整理标点、重复口头语及身份称呼。原话、游戏文字与修改说明分别保存。
- 最终发言按用户要求保留导出记录中的群昵称；没有昵称则不编造。匿名编号只作稳定索引，不替代最终署名，也不声称核验过真实身份或当时昵称。小助手、明确的书中长引文、群接龙名单和未识别媒体不当作书友原创便笺。群发言本身的独创性仍需编辑核对。
- 群里先后谈到同一本书只记为同题接续候选。没有直接回复证据时，`replies`保持为空，不伪装成游戏中某位玩家收到了回应。
- 原导出跨数据库分片，`local_id`有重复。可追溯键采用原文件SHA256、JSON消息数组位置和内容SHA256，不能只依赖`local_id`。
- 原文含个人资料的，只截取有关读书的段落。完整已选原消息放在权限0600的本地private文件，游戏候选里保留用户要求的群昵称，不带微信ID、职业和联系方式。

## 本地重建

将源导出绝对路径传给`--source`，编辑选择JSON传给`--editorial`，将输出放在忽略的本地素材目录：

```sh
python3 scripts/ingest-weflow-materials.py \
  --source /absolute/path/to/weflow-chat-export.json \
  --editorial evidence/real-materials/20261021-qianyi/editorial.json \
  --output evidence/real-materials/20261021-qianyi
```

脚本检查导出身份/哈希、条数、原话精确匹配、唯一来源ID、文字长度和接续关系；输出素材JSON、候选游戏池、原消息对照、逐张审阅稿和哈希清单。不会改写源导出、现有游戏池、玩家存档或发布配置。

## 当前便笺的原文关联

受审阅素材可含`quotation: {text, bookTitle, source, verified: true}`。必须先在本地出处记录核实该版本原文及其与便笺的关系，再标记verified；仅群友转述不够。阅读器同时检查书名和出处。引用从静态素材按便笺ID取得，不信任玩家存档中自填的同名字段；换纸/翻页后跟随当前纸，没有引用就回到书籍简介。原著段落不要伪装成另一位群友的发言。

当前44条运行素材没有已独立核实的对应原著摘录，仍用简介。没有从网上随机补名句。测试里的短/长引文为明确标记的隔离QA fixture，未写入real-materials.js。
