## 实现与来源

44条历史便笺按现有稳定ID关联shelved-selection的source_index，源文件SHA256核对后读取每条原消息日期，核对导出署名和已审阅展示文字。real-materials.js仅增加date，原ID、作者、正文、原文引用和回应字段逐项对比HEAD保持。来源对照在忽略目录evidence/bookshop-v0144/source-dates.private.json（0600），不入Git/部署。

便笺正文下方用原纸张字体显示昵称和年月日，小号淡色落款；左页原文/无原文的简介保持。旧存档中的历史便笺按静态ID补充日期显示，静态审阅日期优先于存档自填日期；旧自写便笺/旧回应无日期不补造。新便笺、新回应各自保存浏览器本地年月日并在重载后保留。没有重写旧正文或清档。

开场页优先未读完整的他人便笺（包含未展开完回应），候选中依次优先其他作者、其他日期、其他纸；所有便笺都读过后继续轮换，单张书仍回看原纸。有新回应的自己的纸优先。未完成交流固定，封面开合/刷新不重抽，完整展纸/回应并实际归架才允许推进。全部纸可经翻页访问，无额度、概率空抽、等待或定时洗牌。没有新增机关或网络共创。
