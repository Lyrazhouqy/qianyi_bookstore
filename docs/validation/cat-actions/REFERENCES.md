# 动作参考与本轮设计

2026-10-23。参考用于动作原则与观察方向，不复制角色、画风或片段。

- [Simon's Cat 官方创作历史](https://simonscat.com/history)：搜索可见介绍以真实猫的行为为创作起点；正文抓取401。本轮不声称完整观看某集或逐帧临摹影片。
- [动画师 Chiara Porri 的尾巴动作教程](https://www.youtube.com/watch?v=3SQqa1Jfo-Q)：作者公开教程的标题与说明明确以跟随/重叠为主题。未获取视频帧，不能把它当作本轮动作测量结果。
- [Animation Mentor：Overlap and Follow-Through](https://www.animationmentor.com/blog/tutorial-animate-overlap-and-follow-through/)：阅读正文，分部位错开启动与收势、注意轮廓和负空间。应用到尾巴末端稍迟跟随、耳朵一前一后、翻身有预备与停留；这些具体姿势与时间是本项目设计判断。
- [SVGator：animated cat guide](https://www.svgator.com/blog/how-to-create-an-animated-cat/)：阅读其公开分部位、转轴与首末姿势衔接方法。最终项目使用重画姿势的逐帧播放，不复制其素材或代码。

最终动作：低位左右扫尾→尾尖跟上→回收；耳朵听声→左右抖耳/半睁眼→眨眼睡回去；蜷肩→侧卧→露肚→伸爪停留→侧身趴好。用户明确纠正扫尾应轻轻左右甩后，竖起尾巴的草稿被撤下，换成低位新画稿。保留三花与原纸感，原文件不做像素扭曲或刚性整猫旋转。
