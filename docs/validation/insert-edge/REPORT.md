# 纸头从真实页边露出：竖书与横书分别定位

2026-10-23。现有 `feat/rhythm-v014`，入口 <http://127.0.0.1:4173/?playtest=rhythm>。原用户标签未操作，刷新加载；本轮没有推送或部署。

## 效果与范围

上一版把小纸角放在`.spine-face`内，虽然跟随了书，但仍画在封面平面上：横书尤其像贴纸。本轮改成独立的页边投影层，复制实际书面的布局、尺寸、旋转及脚部补偿；ResizeObserver在尺寸变化时重新对齐，保留小数像素，不按整个按钮的透明命中区定位。

- 竖书：纸头位于上方白色页块，主要从书顶露出，避开右上角封皮。
- 横书/书摞：纸头位于右侧白色页块，沿页缝伸出，不再画在上方插画封面。下层书摞保留原遮挡，同时给右侧纸头留少量裁切余量。
- 横书拿起转正时，右端映射到书的下沿，因此放大书的纸头也在下沿；竖书仍在上沿。继续继承原拿起/旋转/归架动画，开封面后收隐交给实际便笺。原位投影层与源书同时隐藏，无残留、无点击遮挡。
- 不改变新纸提醒判定、44条真实便笺、原创故事、抽取/已读/回应/草稿、单右下角翻页；未新增外部美术资源。

## 归架穿透修正

定向归架回归发现：下拖放书后，浏览器会向正在归位的`.sid-cover`补发click。原逻辑把此click当成点击背景的下一本书，造成刚放回《悉达多》就误拿起《素食者》。用任务起始HEAD `a956271`的三个原始脚本通过隔离浏览器路由复现，结果与修改版相同，见[基线对照](return-baseline.json)。

最小修正：归架阶段不把`.sid-carrier`内部的点击透传成选书。主动点旁边露出的书脊仍排入下一本，不增加等待或取消这项原功能。
