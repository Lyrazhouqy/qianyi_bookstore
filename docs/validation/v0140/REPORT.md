## 风险、未验证项与用户验收

1. 四拍的自然体验仍待用户判断。一次约六分钟只遇见普通内容，不能据此提高机关曝光或强制导览。
2. 极短便笺的仪式仍可能偏重；本轮只减少其动画开销，没有改变原阅读模型、真实内容或批量新增机关。
3. 明信片为原创演示，插画和文案不是群友留言。首次进入其夹页与取出后都可见区别，但发现感、翻面转折与接力余韵尚需用户体验。
4. 无真人、实体iPhone、真实手机输入法/键盘、手机Safari/网络或新的完整未知目标盲测。交互浏览器工具不可用，没有伪造已完成这类验收。
5. A/B/N仍是原本机模拟；无跨设备异步共创、服务器发布或长期真人回应验证。旧存档无需清除；跨来源不自动迁移。
6. 本地录像是修复前探索；修复后是定向及完整自动化验证，尚未重做一次开放探索。
7. 原生产仍v0.13.0，Vercel部署ID及回退记录保持。用户确认“发现感”和“收尾余韵”后，才可将此开发版发布到原项目，届时另核对READY、资源与访问性。
