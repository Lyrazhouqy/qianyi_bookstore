## 为什么《财政密码》左页固定

`real-materials.js`的`fiscal`有4条真实便笺：`qianyi-fiscal-9993`、`qianyi-fiscal-10102`、`qianyi-fiscal-10157`、`qianyi-fiscal-10169`，均没有已核实的`quotation`。左页采用“本张便笺有同书已核实原文→原文；否则→`content.js`书简介”的既有规则。

“从读几页就困，到清早专门找个地方读，书友留下了不同的尝试。”是之前根据群聊写的**简介占位**，不是原著摘录。这次已向用户说明原因。4张纸当前均回退到这段，所以它不随右页换人/日期而改变。真实群聊/简介原字段保持；没有给这4条添加未经核实的原文。

## 已实现的随机短句

替换顶部“此书留在这里”和简介标题“关于这本书”，8组原创书店闲话：

| 顶部短句 | 简介小标题 |
| --- | --- |
| 本书暂不出差 | 翻开前的小抄 |
| 读慢点，书不赶车 | 先偷看两行 |
| 此处不考阅读理解 | 这本书的开场白 |
| 翻两页，也算串门 | 读前热身两行字 |
| 请坐，书还没讲完 | 先替书说两句 |
| 书没腿，不会跑 | 书脊没讲完的事 |
| 先坐下，再出发 | 先认认这本书 |
| 这页没有截止日 | 开读前透个底 |

每次拿起书抽一组；同本书在本次页面访问内再次拿起时排除上一组。开合封面、翻到其他便笺、展信/收纸、布局变化均保持同组。刷新后重新随机，不新增存储键，不改旧便笺、回应或草稿。配对原文仍固定用“这段话的原文”标识，随机短句只参与装饰和简介小标题。
