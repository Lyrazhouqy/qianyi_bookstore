手机入口：https://paper-bookshop-playtest.vercel.app/v0.14.17/

## 实现

- `room.js`：手机不再强制620px宽或默认向右偏移，按相机实际宽度及安全区计算场景；保持比例、水平完整，短屏原生竖向浏览，旋转后保留对应阅读器。
- `mobile.css`：手机画布与左右安全区对齐，取消为大画布预留的横向溢出；保留独立阅读器、输入区及弹窗尺寸。
- `book-placement.js`：立放书与横放书共同按可见书脊/书名解析重叠触点，避免点到透明按钮覆盖的邻书；键盘按原按钮身份打开。
- 没有“靠近看书”按钮、额外缩放步骤或新菜单。直接点书仍先拿起封面，再点击翻开。
- 阅读、全部便笺、自己的纸、回应、抽取和旧存档规则未改。工作区同时出现的 room-touch、灯绳、花束、挂画修改未纳入本次冻结发布。
