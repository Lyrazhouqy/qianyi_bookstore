# v0.14.5 翻书、取纸与轻翻返回

2026-10-23，现有feat/rhythm-v014开发分支。用户指出取阅缺少惊喜，文字返回入口难找，回应时也应轻量翻回。

## 体验变化

封面轻点/轻扫仍先拿起再翻开，开封面由680ms改520ms、纸角翻页460ms改360ms，已有拖拽跟手/回弹保留。普通便笺取阅改为约190ms抽离＋300ms折面舒展，抬起阴影、折面亮暗、轻微回落形成物件反馈，新纸用纸面暖色反光，无任务弹窗或奖励结算。拖动抽纸也会接续展开，不必再点一次。

纸面右上角加入52×64px的可点/拖翘角，替代底部“折好，放回夹页”长文字。读纸右扫即可翻回，纸角也可向内拖回；普通短/纵向移动不收回。明信片/双面纸左扫翻面、右扫收回，原翻面按钮与键盘方式保留。返回为一次220ms的纸张快照飞折，保持字体/尺寸固定后整体转向夹页，避免逐段收拢或文字重新排版；拖拽的位置和倾角接续进入返回动画。

回应沿用同一纸角与轻扫，返回前读取输入框保存草稿，不自动提交；下次拿笔恢复。保存失败留在输入状态。输入框缩短、按钮简化为“放下笔／夹好”，窄屏进入回应时滚至整个操作区；长文字继续独立滚动，纸角留在滚动区外持续可达。新增上下手势辨别、取消/旋转回弹；正文不误选，输入框仍可正常选字。左原文/右便笺、44条真实内容及日期、作者轮换、旧存档/草稿、原接力信逐折与玫瑰链保持。

## 测试和发现的问题

- 初始兼容36/36，初始手感20/20（手机视口、触摸点按＋鼠标指针拖动）。复看320px截图后收紧回应区；再查26/28，两个小屏明信片高度比原上限多2–3px，收紧纸面空间与图片高度修复，未放宽断言。
- 广泛兼容144/144：日期、重访、翻页角、手感、原文对照、明信片、长信归还与S1–S4。此阶段尚未修复以下原生触摸接管问题，不能把鼠标回归等同于触摸验收。
- Chromium CDP触摸初查失败：触摸有子元素隐式捕获，转交父纸面时，子元素lostpointercapture冒泡被误当作取消，导致轻扫不收回。将纸面、封面、书页角的捕获丢失处理限定为各自真正持有捕获的节点，补充子元素丢失捕获的回归用例。调试脚本首次在阅读器尚未创建时挂事件亦失败，调整为拿书后挂载，不混同产品原因。
- 最终64/64，0失败/跳过/flaky：Chromium/WebKit × 320×568、390×844，覆盖鼠标指针拖动、真实协议触摸点按、纸角/纵向/短拖、取消旋转、草稿不提交与恢复、新回应优先、捕获接管、连点互斥。最终源hash测试前后保持。[分阶段结果及动画实测](test-summary.json)。
- 最终脚本scripts/review-paper-feel-touch.cjs以未替换的真实材料、隔离存档，Chromium CDP在320/390实际发送触摸开始/移动/结束/取消，完成封面拖开、页角拖翻、便笺轻扫、纸角拖回草稿、取消回弹、明信片左扫翻面/右扫收回，无脚本错误。[触摸结果](native-touch-summary.json)。WebKit横扫仍为鼠标指针模拟，物理iPhone、真Safari、真实软键盘/输入法和新盲测尚未验收。

动画帧内计时：普通便笺取阅507–543ms，收回227–271ms，非主观手感或帧率验收。62运行资源本地HTTP字节匹配，[最终源码哈希](runtime-resources.json)；真实素材/日期/发现引擎、原场景/字体/信纸/音乐和资产字节未改。
