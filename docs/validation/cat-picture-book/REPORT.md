证据日期：2026-10-23。现有项目、开发分支 `feat/rhythm-v014`；未推送或部署生产。工作区版本仍由并行任务管理，本任务不独立升全局版本。入口：<http://127.0.0.1:4173/?playtest=rhythm&catbook=daily>；参数仅标识此验收，不改变玩法。

## 实现

旧封面直接放大场景79×105切片，切入了周围书本与书沿，且分辨率低。改用独立1086×1448平面封面，蜂蜜黄色保留识别，用用户图2同款圆润三花猫，封面和桌上书同步同图，100%完整映射，不再引用旧场景裁片。

生成三张独立生活插画：树上的下午、沙发借我半天、替你看一会儿雨。三花斑/粗分段尾巴/圆润造型一致，使用原始PNG；约9.1MB共四图，不预载整册。生成方式与完整提示词见 [素材记录](../../../assets/scene/cat-daily-v01416.prompts.md)。非群聊、非真实原文。

插画是真正右页，左页配原创短句。右下角复用现有曲面翻页；无另起弹窗/抽卡步骤。图片contain完整显示，纸角有空间；书中仍可拿笔留下便笺。原猫便笺、玩家纸、回应、草稿键和值保持，自己的新回应/未读他人纸优先；没有这些时从画册开场，再拿书保留上一张画册页。旧夹页仍与三图在同一本书循环可达。

用户新增文字要求：将猫书简介替换为“本店有位不打卡的店员。上午上树巡视，下午在沙发值班，下雨天负责把窗边坐暖。有人问它工资多少。它翻了个身：小鱼干另算。”此文用于便笺页的左页；画册各页显示对应生活短句。
