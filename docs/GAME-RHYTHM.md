# 纸间书店：书页与便笺节奏

当前开发：2026-10-22，v0.14.0，分支 `feat/rhythm-v014`；生产仍为v0.13.0。以下v0.13.0的全部便笺可读规则保持。依据本聊天用户明确要求：取消45分钟刷新、取消全店三张新纸上限，把一本书的便笺全部放进书页。旧密度规则与历史试玩记录保留在[归档](archive/GAME-RHYTHM-through-v0120.md)，不作为当前规则。

## 当前玩家流程

选书 → 拿起封面 → 翻开 → 一页一张便笺 → 阅读/回应、翻到另一位书友或留下自己的纸 → 合书归位。书里有几个人的便笺，就有对应的纸页；自己的旧纸仍夹在原书另一页，不与别人同屏摊开。

普通便笺与双面纸条采用左右对照：左页显示这张便笺对应的已核实原文，没有则保留简介；便笺在右页取出、展开、回应及收回，不覆盖左页，两侧长文分别滚动。翻页同时更新左右对应关系，仍然一页一张纸。预置接力信、明信片等特殊物件继续复用原逐折/翻面呈现。来源覆盖见[原文对应记录](QUOTATION-SOURCES.md)。

1. 同一本书里的全部便笺始终可经纸角逐页翻阅，包括尚未发现、已经发现、自己留下和带新回应的纸。只有实际翻到/读过才记发现/已读，不在进入书店时把所有纸标成已读。
2. 自己的便笺有新回应时，优先打开这页。普通自己的旧纸不挡住别人的纸；有尚未读完的他人便笺时，开书优先带到其中一张。
3. 随机只决定先遇见哪一张纸，不决定纸能不能读。所有其他纸仍在原书的其他页，不需要额外抽中才能翻到。
4. 只开合封面、未读完便归还、或刷新网页，保持已经选中的开场便笺。读完当前纸及它的回应、整本归架后，再次打开优先带到另一张尚未读完的纸，其中优先不同作者。全部读过后继续轮换旧纸，有多张时避开刚读的那张，有多位作者时优先换人；一本只有一张纸则仍回看这张。翻页本身不重新随机。
5. 只有自己的旧纸、没有别人的纸或预置夹页时，保留简介页 → 自己的便笺页。自己的新回应仍直接优先呈现。

## 已删除的限制

- 无45分钟空闲重置，不按等待时长重新洗牌或清阅读进度。
- 无整轮或全书店三张新纸上限。
- 无55%空抽、跨一本书间隔或长信后两次隐藏新纸。已有别人的纸就可读，留白由玩家翻页/停留/听歌自行形成。
- 无每本书只能新写12张、读取存档只取前24张的截断；原存档中的便笺全部保留，继续写入也不丢弃最早的纸。

正文长度、回应与原机关的约束不是本轮新增或改动的目标；原便笺/回应始终绑定原书和原纸。预置玫瑰/信封/邮票仍沿用原故事前置条件，未把任务奖励提前全部发放。

## 节奏与惊喜

自由阅读与创作是主循环。惊喜来自先翻到谁的话、其他页还有谁、旧纸得到新回应，以及预置跨书线索；不再通过藏掉已有留言或强制空白来控制密度。仍一次突出一张纸，读写时收起翻页角，避免纸角与展信/写字互抢操作。

## v0.14.0 的四种体验长度

这些是可独立发生的体验，不是关卡顺序。没有按分钟、打开书的数量或发现额度解锁的调度，也不保证一次到访遇齐。

- **S1 短惊喜**：《夜航西飞》恢复到墙架，普通便笺页后另有一张原创演示明信片。它不进入随机开场候选，不覆盖已有便笺；翻到该页能看见有色厚边和邮戳轮廓，主动取出看图，再翻面读收件人，可放回并反复取阅。正反面明确写“原创演示”，静态定义的 `source: authored-playtest` 与真实素材及玩家留言分开，不写进便笺池冒充书友。
- **S2 自由探索**：《秘密花园》《海边的卡夫卡》恢复到茶几书摞，原31本均保留，共34本。普通便笺取阅和收回使用较短动画，原接力信逐折时序保留；音乐、窗景和旧纸仍可自由访问。短惊喜结束没有目标、奖励或下一本书推荐。
- **S3 长参与**：主动选《悉达多》，可从页角找到原接力信，A/B/C原文及逐折动作保持。只有最后一段展开后出现续写钢笔，点笔才聚焦输入。未写、取消或直接收书都可离开；续写追加原 `paperbook-v3.replies`。回应草稿放在原有draft对象的 `reply:bookId:paperId` 名下，不覆盖同书新便笺草稿；原格式无需清档或迁移。
- **S4 安静收尾**：折信/归书回到原房间，没有结算、奖励或下一机关推送。整本归位时缩短合拢与飞回的等待，并将长信滚动复位并入归位；主动逐折读信和单独放回纸张的动作仍保留。

纸条在开放书页时的命中层级高于透明页角触区，避免点纸条下缘变成翻页；页角仍保留原76px触区、跟手与回弹。读写/抽取/翻面/归位中均沿用原busy/gesture互斥。

## 本地事件与证据

仅 `?playtest=rhythm` 开启内存事件；不显示调试UI、不上传数据、不新建持久化键。`BookRhythm.export()` 导出副本，`BookRhythm.finish()` 添加session_end后导出。事件只含elapsed_ms、book_id、event_type和白名单枚举/数量；不记录正文、书友昵称、输入内容或凭据。明信片cue只有在纸张实际完整进入视口且书页打开时记录，不在初始化时记发现。

[本轮验收记录](validation/v0140/REPORT.md)包含分阶段结果和5分53秒开放模拟探索。探索没有自然遇到明信片与接力信；不据自动化覆盖宣布情绪节奏成立。可交互浏览器连接失败，实际使用独立agent模拟触控，不是人类或物理手机验收。旧群聊素材、随机开场优先级、全部纸页可读与玫瑰链前置均保持。

## 保存与试玩边界

沿用现有本机存储键，兼容旧额度已用尽、抽取为空的存档，直接恢复可读内容，不要求用户清档。旧known/已读/草稿/自己留言/回应保留；原计数可继续作为历史记录，但不限制阅读。A/B/N为同浏览器模拟书友，尚无跨设备发布和共享服务器。历史群聊素材与明确标注的虚构试玩池继续复用，没有生成冒充真人的新发言。

当前开发入口：<http://127.0.0.1:4173/?v=0.14.0&playtest=rhythm>。URL用于辨认当前版本，本地服务器始终提供当前源码，不是历史快照。

## 验证与下一次试玩

检查自己旧纸与多位书友同书时都能翻到、一页一张、自己的新回应优先；超过三张与跨多书不再受限；41张旧纸及继续新增后刷新不丢失；空闲多日与刷新不洗牌；完整读完归架才改变开场纸，未展开完回应不乱跳。保留页角跟手/回弹、取信、展信、写字和归还回归。

浏览器手机视口/模拟触摸与物理手机验收分开。v0.14.0已做一次开放式agent模拟探索；旧v0.9.0记录仍仅作历史证据。下一步由用户感受“物件的发现感”和“接力后的余韵”，确认体验后才发布原Vercel项目。

## v0.14.4 日期与重复感

真实群友便笺落款显示群昵称和原消息年月日，44条日期由同一导出与稳定便笺ID逐张核对。日期属于每张纸，不是书的统一日期、录入日期或游戏打开日期；已存过的历史纸从静态来源补充显示，不重写原正文/旧回应。自己新写的纸和新回应保存浏览器本地年月日，各自落款；旧纸或旧回应没有可靠日期就不补造。

随机仅决定开场页，优先未读（包括未展开完回应）的纸，候选中优先不同作者；同一作者优先另一天的纸，再避开上张纸。已发现但未展开阅读的纸仍属于未读候选。读完全部纸后继续换人/换纸，不再停在最后一张。自己的新回应优先、未完成交流固定、只开合封面/刷新保持当前纸、必须实际归架才推进，以及全部纸可逐页访问的规则保留。

## v0.14.5 纸张手感

取纸直接接续展读，用抬起、折面展开和落定表现发现感。读纸右扫或点/拖右上翘纸角即可一次翻回，明信片/双面纸左扫翻面；纵向滚动、短拖和取消不收回。回应界面采用同一手势，收回保存草稿而非提交。移除底部冗长的折叠返回动作，回应提交采用“夹好”，纸角返回在滚动区外持续可达。全书归架才推进开场轮换等v0.14.4阅读规则保持。
