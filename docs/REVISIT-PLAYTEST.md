# 《夜航西飞》重访试玩 · v0.8.0

当前v0.9.5通过右页外缘的翘起纸角翻页：轻触，或捏住向内拖动；短拖松手回弹。下角继续翻，同时可前后翻时上角回翻，仅可回翻时用右下角。B仅有自己旧便笺时先见简介页，再翻到旧纸；遇见别人的纸后仍每页只显示一张，新回应优先打开所属页。下文保留v0.8.0历史流程，不能当作当前操作说明。

证据日期：2026-10-20。此页记录v0.8.0固定内容的重访回归场景。新的随机发现试玩见[发现节奏与惊喜设计](GAME-RHYTHM.md)。当前仅本地实现，尚未发布至固定手机入口。

入口：<http://127.0.0.1:4173/?v=0.8.0&playtest=revisit&reader=B>

在书架场景左上打开「本机试玩」纸签，可切换A/B/N。开书时该纸签隐藏，轻点场景空白处收书后再切换。三人是同一浏览器内的模拟角色，不是联网玩家。

- A曾读过这本书，没有自己的留言。
- B曾在书里留下关于远方与回家的旧便笺。
- N随后夹入一张关于飞机和暂缓出发的新便笺。这两张是明确的试玩示例。

试玩顺序建议：

1. 用B打开《夜航西飞》，看见N的新纸和自己旧纸的一角。轻点自己的旧纸能换到它；没有把N的独立留言冒充对B的回应。
2. 取出N的便笺。读完可直接收好，也可点信纸下沿的深红钢笔，写下并夹入回应。
3. 回到书架切到N，再打开同一本书：自己的便笺及新回应优先出现，抽出下面的回应可读到B写的话。
4. 切到A，试读完不回应、收好、再次开书：保持上次纸张，不重复提示已读内容。
5. 用N的顶部钢笔亲自再留一张新纸，切A/B重访，它会成为新的发现。

试玩留言共存在paperbook-revisit-notes-v1。A/B/N的草稿、阅读标记和书店进度分别保存；不会复制、清空或覆盖原paperbook-v3及paperbook-secrets-v1存档。角色切换在书架场景进行。普通入口无试玩纸签。「重演这次相遇」会清空这组试玩角色的进度与留言，再恢复两张示例纸；不影响原存档。

当前边界：没有远端共享存储、跨设备同步、登录身份、推送或“被阅读”的统计。真实回应以保存的文字为准。新纸正面仅在展开后记已读，回应仅在实际展开后记已读。

验证：两引擎四种视口104项、两引擎390原阅读器24项通过，另有320/390 Chromium原生模拟触摸。结果、失败阶段日志和47资源哈希见evidence/bookshop-v080/manifest.json；浏览器检查不等于物理iPhone或十分钟真人试玩验收。
