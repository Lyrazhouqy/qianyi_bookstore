## 实际经过

| 相对时间 | 观察 |
| --- | --- |
| 开始至约2分钟 | 阅读《小王子》，留下自己的便笺，并给它补了一段；试玩者认为回应自己有些奇怪 |
| 约3分钟 | 自行发现音乐选项、换花与窗景；换花是直接的视觉惊喜 |
| 约4分钟 | 在《忒修斯之船》发现干玫瑰与纸条，根据简介自行联想到《小王子》 |
| 约4分40秒 | 重访、切换原夹页、拆信封，取得玫瑰邮票；自己的便笺未覆盖预置线索 |
| 约6—8分钟 | 多本书只有短简介与空夹页，重复感明显；重开《雨天来信》没有刷出新纸 |
| 约8分钟 | 《旧站台》遇见周迟的便笺，写下回应；与书故事贴合的句子重新引起兴趣 |
| 约9分钟 | 重访《旧站台》，自己的回应仍在；没有观察到其他人新增回信 |
| 最后一分钟 | 阅读《森林散步》，留下第三张便笺后结束 |

合计拿书12次，涉及8个书名；留下3张便笺、2次回应。没有严重卡死或阻断探索的故障。书封外起手拖动曾误将书放回；展开纸张后的退出层级，初次使用仍不够直觉。右页书名和页码出现鼠标拖动文字误选，见[截图](../evidence/bookshop-v090/blind-mobile/98-kafka-page.png)。

## 对节奏的判断

本轮支持“具体线索促成重访”和“与书相关的便笺促成回应”；一次寻宝结束后，玩家可以回到自由探索。连续开合没有产生新的惊喜，也没有覆盖已留下的文字。

当前普通探索内容偏薄，特殊事件后的留白又与多本空夹页叠加，导致中段重复。发现调度的功能验证通过，不等于当前密度合适，更不等于长期留存已经验证。本轮没有据一次试玩直接提高概率或再加机关类型。

下一轮优先缩短普通空页的操作成本，检查特殊事件后的间隔与落空保护是否叠加过强，并改善无夹页时的书内内容。保持完整便笺及回应的归属，不用虚构新回复填补空白。自己便笺上的笔是否应表达为“补一句”而非“回应”，也值得单独观察。

## 修复与边界

盲测冻结版本为v0.9.0。其后v0.9.1只补右页文字误选的样式遗漏，保留输入区文字选择；发现概率、额度、间隔、信件池和存档逻辑不变。补丁另做定向回归，不能将本轮盲测说成v0.9.1的第二次十分钟试玩。

试玩信件池是本地虚构示例，真实跨设备发布与新回信仍未实现。刷新稳定、额度和新回应分类另由定向测试覆盖；本轮盲玩没有刷新，也没有证明真实玩家身份或真机手感。线上固定手机入口仍是旧版v0.6.23。
